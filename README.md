Для анализа взят датасет из Kaggle https://www.kaggle.com/datasets/nelgiriyewithana/world-educational-data/data

Данный датасет отражает вовлеченность детей в образование в разных странах по разным грейдам, от дошкольного образования до высшего и соответствующий уровень безработицы.

Задача: создать HTML отчет и сделать выводы по нему.

Результат: помимо отчета через pandas profile report добавил график scatterplot  и интерактивную карту plotly с уровнем высшего образования в разных странах и связь с уровнем рождаемости. Также есть интересная зависимость от участия детей в дошкольном образовании.
